# Tower Exchange Bot
Arc Testnet (5042002) swap activity bot for airdrop farming.

## Scripts
- `tower-swap-bot.mjs` — 25 swaps/day via Tower API (Synthra, UnitFlow, XyloNet)
- `tower-activity.mjs` — Self/cross-wallet transfers
- `faucet.js` — Circle faucet claimer
- `index.js` — Activity bot (transfers)

## Usage
```
node tower-swap-bot.mjs 25
```
